# App_ContextGetLightmapsUsed scope

Retail 0x0048F230 reads DWORD 0x005C8BE4 into EAX and returns without arguments. Binary Ninja and Radare2 agree on six bytes.

Twelve paired Level 1 pre-resume fixtures compare EAX and six mapped DWORDs with fixed values in the other five fields. Retail runs first, Escape is delivered, and globals are restored and checked. Natural consumers, concurrency, unmonitored memory and whole-game equivalence are outside scope. Independent source and probe review found and corrected the candidate symbol before capture.
