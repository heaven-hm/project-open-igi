# 0x0048F240 verification scope

The retail body reads and sign-extends one byte from `[ESP+4]`, writes the 32-bit result to `0x005C8BE4`, and returns. Binary Ninja MCP and Radare2 independently report the same 11-byte, one-block, three-instruction leaf; Ghidra snapshot instructions corroborate the body while its default return type remains low-confidence.

Radare2 ESIL executed the retail body for all 256 byte inputs. The compiled candidate matched the return and mapped `AppContextState::lightmaps_used` value for every case. No live game or IGI-Probe test was available; process-level storage identity and integration remain outside this scope.
