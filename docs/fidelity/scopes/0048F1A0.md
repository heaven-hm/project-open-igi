# 0x0048F1A0 verification scope

Retail reads a signed byte from `[ESP+4]`, sign-extends it to EAX, writes the 32-bit value to `0x005C8BF8`, and returns. Binary Ninja MCP and Radare2 independently report an 11-byte, one-block leaf with three instructions. Ghidra snapshot instructions corroborate the body; its default decompiler return type is low confidence.

The candidate stores the value in `AppContextState::debugged`, the port representation of the retail global. Radare2 ESIL executed the retail bytes for every possible byte input and the compiled candidate matched return and mapped state for all 256 cases. This verifies setter behavior under that state mapping. No live retail process or IGI-Probe trace was available, so process-level storage identity and integration remain outside this scope.
