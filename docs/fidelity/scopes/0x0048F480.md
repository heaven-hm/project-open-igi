# 0x0048F480 verified scope

Verified behavior: the native copies the input low byte to global `0x005C8DE8`; its only caller at `0x00401089` ignores the result. The low return byte matched for all 256 input values when the retail x86 instructions were executed in Radare2 ESIL and compared with the candidate.

The retail body writes AL and does not establish the upper 24 EAX bits. Those bits are outside this verification claim. No live IGI.exe process test was performed.
