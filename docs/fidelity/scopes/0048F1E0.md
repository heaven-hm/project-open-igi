# 0x0048F1E0 verification scope

The retail body sign-extends the byte at `[ESP+4]`, writes the resulting dword to `0x005C8BF4`, and returns. Binary Ninja MCP and Radare2 report the same 11-byte, one-block, three-instruction leaf. Ghidra snapshot instructions corroborate it; Ghidra's default void return is low-confidence.

Radare2 ESIL executed the retail body for every byte input and the compiled candidate matched the return and mapped state for all 256 values. The port represents the retail global as `AppContextState::debug_text_state`. No live game process or IGI-Probe test was available, so integration and storage identity are outside this scope.
