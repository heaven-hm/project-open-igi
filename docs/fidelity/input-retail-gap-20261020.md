This path is provisional and is not evidence that the retail QVM path is reproduced.

The current host controller uses constants documented as script-derived; it does not establish that this native executed or populated its state.

The HumanPlayer source contains an invalid quoted error string and conflicting signature comments, so copying it directly would not establish a correct compilable transcription. Names, ABI, side effects and failure behavior require independent evidence.
